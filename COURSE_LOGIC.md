# Learn CW — Course Logic Audit v2.2

This build fixes the lesson sequencing so narrated transitions correspond to real exercises.

| Lessons | Sequence |
|---|---|
| 1 | Intro → Familiarize T/E/A → Recognition |
| 2–9 | Intro → **actual review of previous characters** → New-character announcement → Familiarization of new characters → cumulative recognition → grouped practice |
| 10 | Alphabet consolidation → individual recognition → groups → continuous-listening marathon |
| 11 | Number introduction → Familiarize 1/2/3 → mixed letter/number recognition → groups |
| 12–13 | Review previous numbers → new numbers → Familiarization → mixed alphanumeric recognition → groups |
| 14 | Real callsign recognition using a fixed callsign set (not random fake strings) |
| 15 | CQ / DE / K explanations → complete general-call practice |
| 16 | R / RST / 599 / 73 explanations → signal-report practice |
| 17 | NAME / QTH / BT explanations → operator-information practice |
| 18 | KN / AR / SK + common abbreviation explanations → operational phrase practice |
| 19 | QSO fragments → complete QSO practice |
| 20 | Guided complete QSO → final Head Copy challenge → transcript → final course message |

Every lesson uses its recorded `lesson_XX_intro` and `lesson_XX_outro`.
