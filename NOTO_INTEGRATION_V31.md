# CW Studio v3.1 — Noto mnemonic integration

## Expected existing production assets

This code expects the SVG subset already generated by `select_noto_mnemonics.py`:

- `assets/mnemonics/es/*.svg`
- `assets/mnemonics/en/*.svg`

The package intentionally does not replace those user-generated SVG files.

## Runtime behavior

1. The app preloads the 36 mnemonic SVGs for the active language when Learn CW
   loads or when a custom session uses Familiarization.
2. Noto colors are remapped in-browser into the CW Studio cyan/ice/dark palette.
3. The Living Line remains continuous.
4. During a mnemonic event the line stays under the visual, is softly masked in
   the center, and the Noto geometry appears with a subtle glow/scale transition.
5. If a single SVG is missing or cannot decode, the old procedural mnemonic is
   used only as a fallback.
6. Offline video rendering also preloads the mnemonic assets before frame 0.

## Updated mnemonic words

The mapping matches the selected Noto pack:
- F ES: Fuego
- L EN: Leaf
- Q EN: Queen
- X EN: X-ray
- Z EN: Zebra
- 7 ES/EN: Palo de hockey / Hockey stick

All other selected words follow the finalized Noto mapping.
