# Morse Practice · CW Studio v1.2

This build follows the repository layout confirmed by PowerShell:

- `assets/voices/course/voice_index.json` = CORE Voice Pack
- `assets/voices/core/course_voice_index.json` = COURSE Voice Pack

Therefore:
- Core audio root is intentionally `assets/voices/course/`
- Course audio root is intentionally `assets/voices/core/`

No audio file is moved or renamed. All MP3 paths are read from the JSON indexes generated by the original Python scripts.

If a lesson-specific file is genuinely absent, the status now reports the exact ID and exact URL that failed.
